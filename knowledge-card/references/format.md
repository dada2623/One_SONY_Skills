# 知识卡片格式指南

从现有卡片库提炼出的格式要素与各类写法要点。写新卡前以此为基准。

## 一、通用结构（每张卡都必须遵守）

```
# 知识点名
#领域标签

一句判断句：它是什么。

要点 1
要点 2
要点 3
[[相关知识点]]
```

### 要素说明

| 要素 | 规则 |
|------|------|
| 标题 | `# 知识点名`，与文件名一致，第一行 |
| 标签 | 紧跟标题下一行 `#领域`，从现有标签复用 |
| 定义 | 标签下一行，一句判断句（"X，是……"） |
| 正文 | 3–15 行骨架信息，不堆原文 |
| 互链 | 提到的其它知识点、文章、播客用 `[[标题]]` |

### 现有标签（优先复用）

`#品牌` `#产品` `#人物` `#技术` `#概念` `#组织`

领域不在其中再自建一个简短中文标签。

## 二、示范卡片（来自现有库）

### 品牌卡 —— 三顿半.md

```markdown
#品牌
SATURNBIRD COFFEE，是正在探索新生活的咖啡品牌
愿景""希望通过不断构建精品咖啡的消费场景，呈现更日常的精品咖啡与生活方式"
主要产品为[[超即溶咖啡]]
![[超即溶咖啡]]
味道排名：现磨手冲（前提是会冲的情况下）优于挂耳，挂耳非常明显好于"超即溶"
```

要点：愿景 + 核心产品（单独成卡并用 `![[产品名]]` 嵌入）+ 与同行比较。

### 产品卡 —— 超即溶咖啡.md

```markdown
介于传统速溶与现磨咖啡之间，通过小罐包装、冷热即溶等差异化设计吸引消费升级人群
```

要点：产品卡可以极简，定位一句话即可；供品牌卡 `![[产品名]]` 嵌入。

## 三、各类卡片写法要点

### 品牌
- 愿景 / 核心产品 / 与同行比较
- 核心产品单独成卡，品牌卡用 `![[产品名]]` 嵌入（图片式引用）
- 可加入主观判断（如味道排名）

### 产品
- 定位一句话 + 关键参数/差异点
- 单独成卡，供品牌卡嵌入
- 极简即可，不必强求多行

### 人物
- 身份 + 一句话履历（时间线式：10年X，5年Y）
- 代表性文章/播客用 `[[标题]]` 链接
- 标签固定 `#人物`，放进 `人物` 子文件夹

### 技术
- 是什么 + 关键指标/原理 + 与同类技术比较 + 代表厂商
- 例：H.265 / RISC-V / IMAP 等卡片的写法

### 概念/定律
- 一句话定义 + 意义/用途
- 例：卡诺循环、伯努利原理、雷诺数

## 四、文件规则

- 文件名 = 知识点中文名，不写日期、不加编号
- 编码 UTF-8，Windows 换行（CRLF）
- 写入前检查同名文件是否已存在：若存在，先读旧卡，在保留原有 `[[wikilink]]` 与要点基础上合并更新，不整张覆盖
