# 知识卡片整理

把一个知识点整理成一张 Obsidian 知识卡片（单个 .md 文件），放入知识卡片库。

## 输出位置

根目录：`C:\Users\dada2\OneDrive\应用\Obsidian\知识卡片`

- 顶层放通用卡片（品牌、技术、概念、组织等）。
- 已有子文件夹 `人物`、`产品`：人物类卡片放进 `人物`，产品类卡片放进 `产品`。
- 禁止新建其它子文件夹，除非用户明确要求。

文件名用知识点本身的中文名，与现有卡片命名一致（不写日期、不加编号前缀）。

## 卡片规范

先读 `references/format.md`，里面有从现有卡片提炼出的格式要素、示范模板和各类卡片的写法要点。写每一张新卡前都要以该文件为基准。

核心原则：**一张卡片讲透一个点**，结构固定、信息密度高、可被其它卡片双向链接。

### 必须遵守

1. **标题 = 知识点名** —— 第一行 `# 知识点名`，与文件名一致。
2. **唯一标签** —— 紧跟标题下方一行写 `#领域`。从现有标签复用：`#品牌`、`#产品`、`#人物`、`#技术`、`#概念`、`#组织`。领域不在其中再自建一个简短标签（中文单字/两字即可）。
3. **一行定义** —— 标签下方一句判断句定义"它是什么"。例如 `SATURNBIRD COFFEE，是正在探索新生活的咖啡品牌`。
4. **用 `[[wikilink]]` 互链** —— 正文里提到的其它知识点、引用的文章/播客，都用 `[[标题]]` 链接，让 Obsidian 关系图生效。不要裸写 URL。
5. **精简** —— 只写卡片的"骨架"，不堆砌原文、不写流水账。篇幅通常 3–15 行。

### 各类卡片偏好（详见 references/format.md）

- **品牌**：愿景 / 核心产品 / 与同行比较。产品本身单独成卡用 `![[产品名]]` 嵌入。
- **产品**：定位一句话 + 关键参数/差异点；单独成卡，供品牌卡嵌入。
- **人物**：身份 + 一句话履历 + 代表性文章/播客链接。
- **技术**：是什么 + 关键指标/原理 + 与同类技术比较 + 代表厂商。
- **概念/定律**：一句话定义 + 意义/用途。

## 工作流

1. 确定知识点名称与所属领域（品牌/产品/人物/技术/概念/组织）。
2. 判断放进顶层还是子文件夹（人物→`人物`，产品→`产品`，其余→顶层）。
3. 按 `references/format.md` 的模板与同类示范写卡片。文件用 UTF-8 编码，Windows 换行（CRLF）。
4. **写入前检查同名文件是否已存在**：若存在，先读旧卡内容，在保留原有 `[[wikilink]]` 与要点的基础上合并更新，而不是整张覆盖。
5. 写入后用 Read 回读一遍，确认标签在首行、标题正确、链接语法无误。
